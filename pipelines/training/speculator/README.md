# Speculator

This subcategory contains pipelines in the **Speculator** group:

- [Speculator Hidden State Extraction Pipeline](./data_extraction/README.md): Extract verifier hidden states for speculative decoding training using managed or remote vLLM.
- [Speculator Offline Pipeline](./offline/README.md): Extract verifier hidden states for speculative decoding training with external vLLM.
- [Speculator Online Pipeline](./online/README.md): Train a draft online, with extraction and training in one Trainer job.
- [Speculator Training Pipeline](./train_only/README.md): Train, evaluate, register, and serve a draft from existing artifacts.
